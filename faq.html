Software & Usage

What is SchoolMate Pro?
SchoolMate Pro is a Windows desktop school data management application designed for Indian schools. It brings school administration activities such as student records, fees, attendance, examinations and reports into one application.
No Internet Connection Required
Internet is needed only to download the installer and for online services like WhatsApp communication or online activation, where applicable. All core school data operations work 100% offline.
Which operating system does it support?
SchoolMate Pro is a Windows desktop application. Please contact support to confirm compatibility with your specific Windows version and computer configuration before installation.
What modules are available?
The application includes school administration areas such as student entry and records, fees, attendance, examinations, leaving certificates, reports, backup and restore, and import/export. Module availability can depend on the selected version and access role.

Demo Download & Installation

How can I download the Demo?
Open the Download & Install page and select Download Demo ZIP. The Demo is provided as a ZIP archive rather than a direct EXE download.
How do I run the downloaded Demo?
After downloading, extract the ZIP archive using Windows Extract All or a compatible archive utility. Open the extracted folder and run SchoolMatePro_Demo.exe. Follow the on-screen instructions. See the illustrated Installation Guide.
Why is the Demo provided as a ZIP file?
The Demo is distributed as a ZIP archive instead of linking directly to the EXE file. Download the ZIP, extract it, and then run the application executable from the extracted folder.
What are the minimum system requirements?

SchoolMate Pro is a lightweight offline desktop software and works smoothly on most Windows computers.

Minimum Requirements:

  • OS: Windows 10 / 11 (64-bit)
  • Processor: Intel Core i3 or equivalent
  • RAM: 4 GB
  • Storage: 500 MB free space
  • Display: 1366 x 768 resolution
  • Other: Internet only for WhatsApp

For best performance, we recommend 8 GB RAM and SSD storage.

License & Support

How do I get Commercial Version pricing or license information?
Pricing and license details depend on the available plan. Use the Pricing section or send an enquiry through the Contact page.
How can I get technical support?
Use the WhatsApp support link on this website or submit the Contact form. The form prepares an enquiry message in WhatsApp; review it and press Send to contact the team.
Does the website form automatically save my enquiry?
No. The current Contact form opens WhatsApp with your enquiry details pre-filled. You must review and send the message in WhatsApp. It does not automatically save the enquiry to a website database or send an email notification.
